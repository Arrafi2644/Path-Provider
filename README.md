
# Pathfinder: Career Counseling Website
### Live site link: https://pathfinder-89c88.web.app

### Overview:
Pathfinder is a career counseling platform designed to guide users in making informed professional decisions. With personalized advice, interactive tools, and expert resources, it ensures seamless navigation for users exploring career paths.

### Features:
- Protected Routes: Secure pages like "My Profile", "Dashboard", "Service Details"  and "Counselor Details" require authentication.
- Authentication: Email-password and Google-based login/registration, with password validation and reset functionality.
- Dynamic Pages: Unique titles for every route with a dynamic data-driven services section.
- Interactive User Experience: Includes sliders, animations (AOS), and toast notifications for feedback.

### Technologies: 
- Frontend: React, Tailwind CSS, DaisyUI
- Routing: React Router
- Backend & Hosting: Firebase (Authentication, Firestore, Hosting)
- Animations & Interactivity: AOS library
